# Photographed textures (ultra tier, photo mode)

CC0 PBR textures from Poly Haven (https://polyhaven.com), 1k, converted to WebP
(colour, OpenGL normal, roughness at 512 px). Used by `photo_textures.js`.

| Files | Source | Real size | Notes |
|---|---|---|---|
| `plaster_*` | painted_plaster_wall | 2 m | colour map high-passed to neutral grain, so the material colour sets the shade |
| `paving_*` | large_grey_tiles | 3 m | |
| `roof_tiles_*` | grey_roof_tiles | 3 m | |
